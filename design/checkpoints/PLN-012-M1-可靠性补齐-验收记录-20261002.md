## 权限与兼容说明

- 新增请求字段（`field_policy`/`confirmed_fields`/`authors`）全部可选，缺省行为与旧客户端逐字一致；
  `IntakeOut.warnings` 为可选字段。无新增授权要求：预检复用受保护 `/health`（无 `members:read` 时
  显示能力未知），reconcile 只用 `books:read` 查询，**禁止直接写数据库**。
- `/recognize/isbn` 依赖不可用从 400 改为 503（能力故障如实报告；与 intake 端点既有 RuntimeError→503 口径对齐）。
- 清单：v1 可读、升级前备份 `.v1.bak`、高版本拒绝写回；历史 `result` 原样保留。
- 回退：恢复旧版脚本即可继续读 v1 清单（v2 清单对旧工具会明确拒绝，需先手工降级或用备份）；
  后端新增字段为可选，回退后端不影响旧脚本。

## 剩余限制（显式记录）

1. **M1 幂等边界**（规划 §4.5）：客户端保存成功状态与服务器提交之间仍可能断开；仅有书名去重，
   `outcome_unknown` 重发不承诺副本/购买记录恰好一次——M3 由 CommandExecution 幂等键消除。
2. OPT-015 的"裸 ISBN 标题"部分未实现（需产品决策是否引入"待补全"状态），确认值保护部分已由
   BI-03 覆盖；旧库 id 2/3/4 存量清理仍待办。
3. 元数据链结构未变（nlc 超时占用批次窗口、google_books 无 Key 限流）；诊断工具已可量化，
   是否配置 API Key/扩提供方属后续运维决策（契约 §8.4）。
4. `metadata_missing` 警告当前不区分"真无结果"与"外部依赖故障"（后者需观察钩子数据，业务链路
   未接入）——留给 M2 视觉服务统一处理外部故障分类。
