## 执行主体与安全边界（BI-12 冻结内容）

1. **Human Workflow**：确认决策（Decision）绑定发起人（Owner member_id）、候选版本与命令；执行入口 `POST /work-items/{id}/execute` 每次经 `require_owner` 重新鉴权——Owner 停用/会话失效即 401/403，不存在转借 Cookie。
2. **Worker 证明**：M3 首版执行器运行在后端进程内（与 API 同信任域），不涉及跨进程执行证明交换；若后续引入独立 Worker/内部 Agent Runner，须另行冻结 Client/Grant 与版本绑定方案（规划 §4.8 原文要求），不得隐式更换执行主体。
3. **写入路径**：书目创建只经领域服务 `intake_book`（`prefer_confirmed` + 确认字段），模型与候选对象无任何直写图书库路径；`link_photos` 不修改已有书字段（缺封面回填除外）。
4. **权限**：工作台不随 `books:write` 开放（Member/Agent 403 已验证）；照片图片走受认证读取。
